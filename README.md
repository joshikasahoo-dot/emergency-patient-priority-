overview of the project: The Emergency Patient Priority System is a simple Python project designed for a healthcare setting. It collects basic patient information and vital signs, then uses predefined rules to calculate a priority score and assign a priority level.
The main goal is to make it easier to organize emergency patients based on their recorded condition.
Features
Add and store patient details
Record basic vital signs
Calculate a priority score
Assign a priority level
View patient records
Arrange patients according to priority
Technologies Used
Python
Functions
Lists and Dictionaries
Conditional Statements
Sorting
